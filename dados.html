Cadastro de Operação — Compra de Direitos Creditórios

Modo: Desconto
No modo Desconto você informa o VF (valor futuro / recebido na data) e o sistema calcula o VP.
No modo Inverso você informa o VP (valor nominal do cheque) e vê o PV (valor presente após desconto).
Se os valores das parcelas forem deixados em branco, o sistema divide este valor igualmente entre as parcelas.
Os cálculos usam desconto simples com base de 30 dias por mês.
Data em que a operação foi realizada (D0). As datas das parcelas são comparadas com D0 para calcular os dias corridos.
Data em que a operação vence (será atualizada automaticamente para a data da última parcela).
O sistema usará D0 + 30/60/90... dias corridos como padrão. Se a data cair em fim de semana, será ajustada para a próxima segunda-feira.
